GMENU – a small game menu for DOS / DOSBox.

**Install:** unzip `GMENU-v0.2.1.zip` to the root of the DOS C: drive (`C:\GMENU`), set the game directory in `GMENU.BAT`, and start the menu with `\GMENU\GMENU`. To update 0.2.0, replace `GMENUPRG.COM`.

- ↑ on the first game jumps to the last one, ↓ on the last to the first (also in the file list)
- The source is split into modules under `SOURCE/` (no change in use)
