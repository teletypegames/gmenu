GMENU – a small game menu for DOS / DOSBox.

**Install:** unzip `GMENU-v0.3.0.zip` to the root of the DOS C: drive (`C:\GMENU`), set the game directory in `GMENU.BAT`, and start the menu with `\GMENU\GMENU`. To update an older version, replace `GMENUPRG.COM`.

- Favorites: F6 marks a game (yellow `*`), F7 shows only the favorites; kept in `GMENU.FAV`
- Recently played games: F8 lists the last 10
- Mouse wheel support (CuteMouse WheelAPI)
- The header shows how many games match a search or filter (`Found: 42 of 318`)
