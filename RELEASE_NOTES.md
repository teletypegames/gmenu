GMENU – a small game menu for DOS / DOSBox.

**Install:** unzip `GMENU-v0.2.0.zip` to the root of the DOS C: drive (`C:\GMENU`), set the game directory in `GMENU.BAT`, and start the menu with `\GMENU\GMENU`. See `README.md` for `METADATA.INI`.

- `METADATA.INI` per game: `NAME`, `GENRE`, `YEAR`, `PLAYERS`, `DESCRIPTION` (`NAME.TXT` still works)
- Game list as a table: title, genre, year, folder
- Detail page: all the game's data and its files; Tab shows all files, `/A` makes that the default
- Search in titles, folder names and descriptions; filters by genre, year and number of players (F2 / F3 / F4, F5 clears them)
- The menu remembers the selected game, the search and the filters
