GMENU – a small game menu for DOS / DOSBox. First version.

**Install:** unzip `GMENU-v0.1.0.zip` to the root of the DOS C: drive (`C:\GMENU`), put the games in `C:\COLLECT` (one folder per game, with a `NAME.TXT`), and start the menu with `\GMENU\GMENU`. See `README.md`.

- Lists the game folders of `\COLLECT`, named after the first line of each folder's `NAME.TXT`
- Starts any `.COM`, `.EXE` or `.BAT` file of the selected game; the menu is not in memory while the game runs, and it comes back on the same game
- Keyboard and mouse, search
